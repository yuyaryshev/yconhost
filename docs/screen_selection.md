# Выделение текущего экрана

Кнопка «Выделить» открывает поверх терминала read-only текстовый снимок текущего
viewport активного буфера xterm, в том числе alternate screen TUI. История вне
экрана не включается. Текст уже разобран терминалом: без ANSI-команд и старых
следов перерисовки. Мягкие переносы склеиваются, настоящие переводы строк остаются.

Поле использует текущие шрифт, размер, высоту строки и цвета терминала. Снимок
не меняется при новом выводе. Терминал не удаляется, не скрывается через display
и не меняет размер; его DOM становится inert на время выделения. Протокол,
поток вывода, мышиные режимы TUI и обработка ответа терминала не меняются.

После выделения мышью/пером и отпускания указателя непустой фрагмент копируется
через Clipboard API. Оверлей закрывается только после успешного копирования.
При отказе браузера выделение остаётся, появляется ошибка; доступны кнопка
«Копировать» и обычное системное копирование из текстового поля. На touch-экране
используется кнопка или системное меню копирования, чтобы не прерывать настройку
границ выделения. Esc, крестик и повторное нажатие «Выделить» отменяют режим
без копирования. После закрытия фокус возвращается терминалу.

При смене консоли, перезапуске или пересоздании xterm снимок закрывается.
Backend не изменён, перезапуск сервиса для выкладки UI не требуется.

## Проверка 2026-11-05

Пройдены typecheck, production-сборка и 82 теста в 14 файлах. Новые unit-тесты
проверяют мягкие/жёсткие переносы, пробелы на границе строк, широкие символы,
viewport без старого scrollback, ANSI, alternate screen и неизменность буфера.

Playwright на отдельном экземпляре с FakeTerminalFactory: реальное выделение
мышью с копированием в системный clipboard, ID через мягкий перенос, отмена,
обычное копирование, отказ Clipboard API с сохранением выделения и успешный retry.
Проверено, что снимок не меняется от нового вывода, а исходный терминал продолжает
обновляться. Во время выделения не отправлено ни одного input/resize-сообщения,
размер xterm не изменился; после закрытия фокус и ввод восстановлены.
Смена сессии и restart закрывают снимок. Пройдены desktop 1440x1000 dark и
mobile 390x844 light, включая видимость кнопок при прокрутке и начальную загрузку
экрана: «Выделить» недоступно до разбора первого ответа `/output`.

# Палитры Фона Консоли

## Текущая Палитра

После уточнения пользователя 2026-11-12 остаются 14 нетусклых оттенков
из комбинаций `00/19/32` и отдельный чёрный образец. Исключены все варианты
с двумя компонентами `19`: `#321919`, `#191932`, `#193219`, а также
`#193200` и `#003219`. Повторное случайное распределение контекстов использует
только эти 14 оттенков, без чёрного. История первоначального расширения ниже
описывает предыдущий вариант палитры.

## Причина Расхождения

2026-11-09: на пользовательском скрине в Paint зелёная линия и реальный
фон терминала имеют цвет `#003200` (RGB 0,50,0). В диалоге выбора были
только `STD_*` образцы: `STD_GREEN` в тёмной теме равен `#0c140c`
(RGB 12,20,12). Это разные цвета, а не прозрачность или затемнение CSS.
Предпросмотр конкретного `#003200` в Console settings был верным.

## Исправление

Диалог Background теперь содержит:

- `Current color`: исходный цвет записи, с возможностью выбрать его снова.
- `CLI colors`: привычные точные RGB-пресеты `#000000`, `#320000`,
  `#003200`, `#000032`, `#323200`, `#003232`, `#320032`, `#323232`.
- `Standard colors`: прежние `STD_*` значения без изменения семантики.

2026-11-12: CLI-палитра расширена до всех 19 комбинаций компонент `00`, `19`,
`32`, в которых есть хотя бы одна `32`. Включены варианты с двумя `19`
(`#321919`, `#193219`, `#191932`) и двумя `32` (`#323219`, `#321932`,
`#193232`), а также все перестановки `00/19/32`. Старые 7 цветных пресетов
сохранены. Чёрный `#000000` остаётся отдельным двадцатым образцом, но не входит
в случайное распределение по контекстам. Тусклые варианты только из `00/19`,
например `#190000` и `#191900`, не добавляются. Значения `STD_*` не меняются.

Выбор CLI-пресета сохраняет точный HEX. STD сохраняется как именованное
значение. Выбранный образец отмечается по фактическому RGB, поэтому
`rgb(0, 50, 0)` и `#003200` выделяют один CLI-пресет. Применение/отмена и
произвольный выбор через react-colorful сохранены.

Явные RGB/HEX цвета одинаковы в обеих темах; только STD-пресеты имеют
различные тёмный/светлый варианты. Изменение диалога не переписывает
конфигурацию и не меняет фоны уже существующих консолей.

Рабочий сервер `4011` не обновлять без отдельного согласования: пользователь
запретил останавливать текущие консоли. Проверка выполняется на `4021`
и отдельном `data/folder-verification`.

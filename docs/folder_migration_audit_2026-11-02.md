## Блокеры

### 1. Ошибки определения типа старых папок

`FolderService` выводит `my_wins` из наличия `projectPath`, хотя путь может означать
лишь контекст ручной MCP-консоли. Затем `adoptRegistry()` заменяет отсутствующий
тип старой записи на `manual`, теряя ранее выведенный тип.

Наблюдаемый результат:

- `odbp_bundle` становится `manual`, хотя содержит консоли из mywins; файл больше
  не синхронизируется автоматически.
- `CodexGarden` становится `manual`. Там есть mywins-файл, но текущие два слота
  являются MCP-задачами, а не его записями. Само наличие файла не доказывает,
  что пользователь хотел конвертировать ручную группу в файловую.
- `yy_modpack_1_20_forge_server` и `ai2u_loghud` становятся `my_wins` без
  существующего источника. В UI появляется ошибка отсутствующего mywins-файла;
  старые слоты сохранены защитой от неуспешного обновления.

Нужна миграция с учётом происхождения слотов, а не одного `projectPath`,
и сохранение выбранного типа при чтении старого реестра.

### 2. Конфликты источника codexes

Обновление отклоняется с `Duplicate folder entry key or name`, все 82 старых
слота остаются из кеша. Выявлены два независимых конфликта:

1. Две записи используют `resume factorio`: `factorio (modding)` и
   `factorio (modding) olga - do unismelting here`. Это псевдоним, а не GUID.
   Новый скрипт ошибочно использует его как уникальный ключ обеих записей.
   Нужен согласованный fallback на имя для записей без уникального GUID.
2. В `D:\b\InfoVault\Codex contexts.md` два заголовка `khb_agent_claude`
   (строки 938 и 946 на момент проверки), но разные команды:

```cmd
cls && cd /d D:\b\Mine\GIT_Work\khbuild_docs && claude --resume 483c2dfb-4ef5-45ea-975b-d39f324e7f53 --dangerously-skip-permissions
cls && cd /d D:\b\Mine\GIT_Work\khb_microservices && claude --dangerously-skip-permissions
```

Существующий слот использует **первую** команду. Без разрешения конфликта нельзя
подменять её второй: это другая папка и новая сессия вместо продолжения старой.
Отклонение конфликтного списка защищает от такой подмены, но блокирует весь импорт.
Нужно согласовать разные имена либо другой явный способ разрешения дубля.

- `other00`

Запущенные слоты, отсутствующие в источнике, по контракту должны оставаться

из-за совпадения рабочей директории: текущая группа могла быть создана как manual.

# Исправления миграции и повторная проверка, 2026-11-02

Продолжение [первичного аудита](folder_migration_audit_2026-11-02.md).

## Реализовано

- Старые batch-папки распознаются как `my_wins`; сохранённый или выведенный тип
  не теряется в `adoptRegistry`. Ручные MCP-папки не становятся файловыми только
  из-за `projectPath` или существующего файла в рабочей директории.
- Дубли имён/ключей сообщаются с конкретными значениями и именами записей.
  В codexes проверка происходит до дедубликации команд, иначе одинаковые команды
  скрывали повторяющийся идентификатор. Неверный список не заменяет последний
  корректный. Ошибка видна текстом в UI даже у свёрнутой папки.
- MCP-запись в `my_wins` требует `confirmSourceWrite: true`, отдельно от
  подтверждения удаления. Без него файл не меняется: ответ содержит путь,
  предупреждение и совет править файл напрямую, затем перечитать источник.
  Временные консоли следует создавать в отдельной manual-папке. Указания есть
  и в описаниях инструментов, и в ответе на реальную попытку изменения.
- Фон строки sidebar совпадает с фоном соответствующего терминала, без
  смешивания с фоном sidebar. Выбор отмечен рамкой и не меняет цвет. Цвет текста
  подбирается по контрасту, в том числе для тёмного явного RGB в светлой теме.
